## 결정됨

- **3개 코어 레포(`hyper`, `ring`, `lace`) 분리 및 Rust 모노레포(`apps/`, `crates/`) 구조 확정** (2026-11-16 ~ 2026-11-18)
  - 영향: `docs/00`, `05` (기존 웹/네이티브 UI 레포를 `lace` 단일 레포로 통합)
- **`docs`는 범용 추상 계약만 다루고, 제품·레포별 세부는 각 코드 레포 문서에 위임** (2026-11-16)
  - 영향: `README.md`, `docs` 전체
- **Rust 코어 기반 + `hyper` 코어(`ref`) 수직 통합 + 외부/타깃 호환 어댑터 분리** (2026-11-16 ~ 2026-11-17)
  - 영향: `docs/00`, `02`, `03`, `04`, `05`, `06`
- **내부 포크 + 단계적 `unit optimization` 운영 확정** (2026-11-16 ~ 2026-11-17)
  - 이유 및 내용: 1단계(범용 추상화·미사용 피처 제거 및 `hyper` 코어 직결) 기본 적용 후, 병목 구간에 2단계(Arena/SoA·SIMD 등 심화 개조) 여지 확보 (`docs/05` §7)
- **생산성 중심 표현 수단 개방성 및 컴포넌트 기반 아키텍처 고점 개방 확정** (2026-11-16 ~ 2026-11-18)
  - 이유 및 내용: DSL은 개발 생산성을 위한 수단일 뿐 더 효율적인 방법(순수 Rust 빌더 등)이 있으면 무엇이든 허용하며, 고정된 폴더 구조를 강제하지 않고 컴포넌트 조립으로 아키텍처 고점을 높임 (`docs/00`, `01`)
