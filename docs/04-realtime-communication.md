# 04. 실시간 통신 어댑터 규약 (WebSocket)

> 상태: **제안** · 기준일: 2026-11-16

외부 호환 어댑터 중 **WebSocket 어댑터를 채택하는 경우** 그 어댑터가 따르는 공통 규약입니다. 외부 호환이 반드시 WebSocket인 것은 아닙니다. 코어·내부 규약 모델은 표준보다 성능과 수직 통합 생산성을 우선하고([00-vision](00-vision.md)의 규약 모델 원칙), 이 문서는 외부 어댑터 중 하나의 규약 제안입니다. HTTP 어댑터 규약은 [03-api-protocol](03-api-protocol.md), 어댑터 공통 계약은 [02-core-contracts](02-core-contracts.md) §5~§7을 따릅니다.

이 문서는 **연결·메시지 봉투·순서·재연결 같은 프로토콜 수준 규칙**만 다룹니다. 메시지의 도메인 종류, 동기화 단위의 의미, 수치 한도는 이 어댑터를 구현하는 쪽이 정합니다.

## 1. 연결 수명

1. 클라이언트는 먼저 다른 인증 경로로 인증하고 **단기 일회용 티켓**(짧은 만료 시간, 1회 사용 즉시 소진)을 받아 연결합니다. 브라우저 WebSocket API처럼 커스텀 헤더를 쓸 수 없는 환경을 고려해 단기 일회용 티켓만 쿼리 파라미터(`?ticket=...`)로 전달해 핸드셰이크 시 검증·소진하며, 연결 URL에 장기 자격 증명이나 세션 토큰은 절대 싣지 않습니다.
2. 연결 후 첫 메시지로 프로토콜 버전을 알리는 `hello`를 보냅니다.
3. 서버가 연결을 닫을 때는 표준 close code와 사유를 보냅니다.

## 2. 메시지 봉투

- 텍스트 프레임, JSON, UTF-8을 씁니다. 대용량 데이터는 이 채널에 싣지 않습니다([02-core-contracts](02-core-contracts.md) §7).
- 클라이언트 → 서버: `type`, `id`, `payload`. 필요하면 `clientTs`(참고용이며 순서·신뢰의 근거가 아님).
  - `id`는 **클라이언트가 만드는** 고유 값이며 요청-응답 대응과 중복 제거에 씁니다.
- 서버 → 클라이언트: `type`, `id`, `seq`, `ts`, `payload`. 응답이면 `requestId`(요청의 `id`).
  - `id`는 **서버가 만드는** 이벤트·메시지 고유 값입니다.
  - `seq`는 **서버가 부여하는** 동기화 단위별 단조 증가 값이고 `ts`는 서버 시각입니다.
- `type`은 `대상.행위` 형태의 소문자입니다. 요청은 명령형, 서버 통지는 과거형·상태형입니다.
- 실패는 `type: "error"`에 [03-api-protocol](03-api-protocol.md) §4와 같은 `code` 규칙을 씁니다.

## 3. 순서와 상태 유지

- 여러 접속자가 같은 상태를 공유하는 경우, 그 순서를 정하는 주체(조정자)와 `seq`의 유지 방식은 구현이 정하고 문서화합니다. 조정 구조의 선택 기준은 [02-core-contracts](02-core-contracts.md) §4를 따릅니다.
- 재연결 복구가 필요한 `seq`와 상태는 재시작을 견디도록 영속화합니다.

## 4. 연결 유지

- 단절 감지는 주기 ping/pong 또는 클라이언트 타임아웃 중 구현이 고릅니다. 간격은 구현이 정합니다.
- 상태 조정자가 휴면(hibernation)을 지원하는 환경에서는 앱 레벨 핸들러가 휴면을 깨우지 않도록 엣지/플랫폼 수준의 자동 응답(`ping` → `pong` auto-response)을 우선 사용합니다.
- 서버는 연결 종료 시 해당 연결의 상태를 정리합니다.

## 5. 재연결과 복구

- 클라이언트는 지수 백오프와 지터로 재연결하고 상한을 둡니다.
- 재연결 시 마지막으로 받은 `seq`를 보내 누락분을 받습니다. 서버가 그 지점을 모르면 전체 스냅샷으로 재동기화합니다.
- 끊긴 동안의 요청은 큐에 쌓아 **원래 `id` 그대로** 순서대로 재전송합니다. 서버는 `id`로 중복을 제거해 같은 요청의 부수효과를 반복하지 않습니다.

## 6. 제한

- 메시지 크기·속도 제한을 두는 경우 구현이 수치를 정하고 문서화하며, 초과하면 `error`로 알립니다.
