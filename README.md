# hyperish/docs

하이퍼리쉬(Hyperish) 제품군의 설계·규약 문서 레포입니다.

첫 제품은 리얼리스틱 그래픽 엔진이고, 이 레포는 그 엔진과 앞으로의 크리에이티브 툴 패밀리(벡터·셰이더·사진 편집) 전체가 따라갈 문서의 뼈대입니다.

## 문서 상태 규칙

모든 문서와 절은 셋 중 하나의 상태를 표시합니다.

| 상태 | 의미 |
|---|---|
| **확정** | 명시적으로 결정된 사실. 바꾸려면 리뷰 승인과 새 결정 기록이 필요하다 |
| **제안** | 논의를 위한 설계안. 바꾸기 쉽게 적은 것이며, 확정이 아니다 |
| **미정** | 아직 결정되지 않은 사항. `docs/11-open-questions.md`에서 추적한다 |

규격(숫자, 한도, 포맷)을 적거나 바꿀 때는 근거(공식 문서 링크 등)와 확인 날짜를 함께 남깁니다.

## 문서를 바꾸는 법

- 커밋은 문서 단위로 나눕니다. 한 커밋에 관계없는 문서를 섞지 않습니다.
- 커밋 메시지 규약은 [개발 규칙](docs/09-development-rules.md)을 따릅니다. 이 레포의 커밋은 보통 `docs:` 타입입니다.
- **제안** 문서의 내용을 **확정**으로 올리는 변경은 리뷰 승인과 명시적인 결정 기록이 있어야 합니다.
